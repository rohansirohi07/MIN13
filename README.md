🌍 AQI Prediction & Air Quality Analytics System
📌 Project Overview
This project is an Air Quality Index (AQI) Prediction System that predicts air quality levels based on major air pollutants. The system also provides analytics and report generation to help understand pollution trends.

The prediction is performed using machine learning models, and the application allows users to input real-world pollutant values to get instant AQI results.

🎯 Objectives
Predict AQI value based on pollutant concentrations
Analyze air quality trends
Generate reports for better decision-making
Provide a simple and interactive interface for users
🧪 Pollutants Used for Prediction
The AQI prediction is based on the following parameters:

SO₂ (Sulphur Dioxide)
NO₂ (Nitrogen Dioxide)
CO (Carbon Monoxide)
PM2.5 (Fine Particulate Matter)
PM10 (Coarse Particulate Matter)
O₃ (Ozone) (optional if included)
⚙️ Features
✅ AQI prediction using ML model
✅ Real-time input of pollutant values
✅ AQI category classification (Good, Moderate, Poor, etc.)
✅ Air quality analytics and visualization
✅ Report generation for analysis
✅ User-friendly interface

🧠 Machine Learning
Data preprocessing and feature scaling
Model training using historical AQI data
Model evaluation and optimization
Prediction using trained model
📊 AQI Categories
AQI Range	Category
0 – 50	Good
51 – 100	Satisfactory
101 – 200	Moderate
201 – 300	Poor
301 – 400	Very Poor
401 – 500	Severe

🚀 How It Works
User inputs pollutant concentrations (SO₂, NO₂, CO, PM2.5, PM10, etc.)
Data is processed and passed to the trained ML model
The model predicts the AQI value
AQI category is determined
Analytics and reports are generated
